# Concept F — EGOIST Signal

Broadcast-style Guilty Crown / EGOIST feed: high-contrast light paper, black ink, and orange-red “live signal” accents. A fixed spine column and diagonal header gradient split the layout from the dark terminal and glass void themes.

The header runs animated CSS signal bars (seeded in `app.js`) with a scan overlay, evoking a waveform monitor without copying production Guilty Crown CSS.

Projects render as **transmission cards** in an asymmetric 4-column bento grid (2×2, 2×1, 1×2 spans). Featured items get a priority bento row. Links are **Visit** only. Shared theme registry, landing redirect, and switcher match other concept previews on port **8095**.
