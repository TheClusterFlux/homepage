# MWPSB Dossier (Concept O)

The homepage reads as a **Division 1 case file cabinet** under cool fluorescent grey — not a product grid. Each project is a **manila folder** with tab ID, rotated **CONFIDENTIAL** (or **PRIORITY** for featured) stamp, and a **mugshot + synopsis** split: thumbnail as desaturated ID photo, description with inline **redaction bars**.

Featured projects map to **priority cases** in a separate stack above the archive scroll. Crime Coefficient numbers are decorative hashes from titles only. Links are **Visit subject** — no source/repo exposure. Typography: Rajdhani + Share Tech Mono per `PSYCHO_PASS_BRIEF.md`. Preview port **8101**, theme id `mwpsb-dossier`.
