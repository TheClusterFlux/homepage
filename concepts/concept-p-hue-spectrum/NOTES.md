# Hue Spectrum — design notes

The page is a **Sibyl-style latent scan**, not a card grid. A vertical (or horizontal on narrow screens) gradient bar maps clear cyan → cloudy purple → criminal magenta. Each project’s **title hash** picks a fixed position and accent color on that bar.

**Cymatic canvas** fills the viewport with slow Chladni-like interference tinted by the same spectrum, so the background feels like an active scan rather than static wallpaper.

Interaction centers on **markers on the rail** plus a detail panel: hover previews the cursor line; click or list selection locks the subject. Arrow keys walk subjects sorted by pseudo-hue. Featured items appear as a clear-band chip row. The registry list below keeps search/filter parity with other concepts; links are **Visit only**.

Typography uses Chakra Petch + Share Tech Mono for MWPSB clinical readouts. Decorative “HUE n” labels are explicitly not real Crime Coefficients.
