# Dominator Lock (Concept N)

Psycho-Pass **Dominator acquire UI**: projects render as lock-on targets with **corner reticles** and per-card **scan sweeps**, not a uniform card grid. Featured work sits in an **eliminator** band (orange / magenta); the paralyzer queue uses **sky-blue** accents and **staggered horizontal offsets** so rows feel like a targeting stack.

Angular **clip-path panels** frame the HUD header and each target. Monospace **Share Tech Mono** plus **Rajdhani** carry CC-style decorative readouts (not real scores). Full-viewport scope grid, faint crosshair, and global sweep reinforce the scanner mood.

Data from `/data/projects.json`; thumbnails from production CDN. Search, category filter, featured row, **Visit-only** links. Shared theme scripts; preview port **8100** (`data-visual-theme="dominator-lock"`). Visual palette notes: `../PSYCHO_PASS_BRIEF.md`.
