# Crystal Cathedral — Concept B

The page is a full-viewport void: layered CSS aurora, drifting inline-SVG crystal shards, light ribbons, and mouse-driven parallax on the radial core—no terminal chrome and no equal SaaS card grid.

Projects render as **glass slabs** with deterministic variant shapes (prism clip, tall/wide media, shard radii, compact copy) and slight per-card rotation so the masonry column layout feels like floating debris, not a HUD roster.

Typography pairs **Cormorant Garamond** (liturgical display) with **Syne** (wide light UI). Featured projects sit in a “Luminaries” constellation row with stronger cyan–magenta glass; the archive uses CSS multi-column masonry.

Data and behavior match production: `/data/projects.json`, production thumbnail URLs, search, category filter, featured section, and **Visit** links only (no source). Local preview: `npm run concepts` → http://127.0.0.1:8092.
