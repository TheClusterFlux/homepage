# Paper Crane

Light washi and origami — cream fiber backdrop, soft indigo and vermillion ink washes, Cormorant titles. The header is a **folded sheet** (clip-path corner + shadow offset), not a flat hero bar.

Projects render as **kite-fold cranes** (diamond clip-path, diagonal crease, chamfered thumbs). Featured **Horizon Folds** sit in a loose horizontal row with stronger vermillion emphasis. The main **Flock** uses a responsive grid with slight rotation offsets so cards feel hand-placed, not a uniform SaaS grid.
