# Sakura Genome — Concept D

Light **Guilty Crown** mood: soft pink and cyan, Orbitron + Rajdhani, crystalline grid haze—not a terminal shell and not a floating glass card grid.

**Featured band** — horizontal genomic strip at the top (scroll-snap cards with diagonal stripe overlay). **Main list** — vertical **genome spine**: animated helix rail beside a timeline of nodes connected by gradient tethers; each node is a sharp-edged card with SEQ index, category tag, thumb, and copy.

CSS includes falling **sakura petals**, ambient blooms, spine pulse travel, and helix strand motion. Respects `prefers-reduced-motion`.

Data matches production: `/data/projects.json`, thumbnail base `https://homepage.theclusterflux.com/thumbnails/`, search (`#search-bar`), category filter (`#category-filter`), featured section, spine timeline (`#projects-grid`). **Visit** links only.

Theme switcher: `/shared/theme-registry.js`, `/shared/theme-bootstrap.js`, `/shared/theme-switcher.js`. Body: `data-visual-theme="sakura-genome"`.
