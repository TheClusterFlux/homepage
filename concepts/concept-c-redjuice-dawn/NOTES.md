# Concept C — Brutalist Editorial

Paper-toned `#f4f0e8` base with Bebas Neue display type and thick black rules, deliberately avoiding soft SaaS cards or gradient pills. The lead featured project fills a split hero with an 8vw-scale title; remaining featured items scroll horizontally with snap. The archive uses a 12-column asymmetric grid (every fifth item spans eight columns) so the page reads like a magazine spread, not a uniform portfolio grid.

Background motion comes from three blurred CSS mesh blobs plus an SVG noise layer stepped on a short loop for print-like grain. Visit links are the only outbound actions—solid rectangular buttons with invert-on-hover, no source links. Search and category filter apply across hero, strip, and archive via local `app.js`.
