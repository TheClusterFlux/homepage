# ClusterFlux concept themes — Guilty Crown research

Reference: *Guilty Crown* (Production I.G / redjuice). Portfolio redo for TheClusterFlux homepage.

## Visual language (show + redjuice promo art)

| Element | Treatment |
|--------|-----------|
| **Void / Apocalypse Virus** | Crystalline shards, glass-like fractures, cyan–green inner glow, black negative space |
| **Void Genome / King's Power** | Silver metallic UI rings, sharp geometric HUD, thin technical sans-serif labels |
| **GHQ vs Funeral Parlor** | GHQ: cold clinical white-on-grey military readouts; Funeral Parlor: darker tactical HUD, resistance ops aesthetic |
| **Typography** | Futuristic gothic sans (Rajdhani/Orbitron family on web); wide letter-spacing, uppercase labels, UI-not-decoration |
| **Color** | Silver `#c0c0c0`, ice blue `#60a5fa` / `#93c5fd`, deep void `#0a0e14`, optional Inori magenta `#e879a9` / coral accent |
| **Motion** | Slow ambient ribbon/particle drift; crystalline fragments, not bubbly gradients |

## Page structure (all concepts)

- Header: logo, title, search, category filter, theme toggle, GitHub
- Featured row (3 cards max)
- All projects grid
- Project card: thumbnail, category badge, title, description (3 lines), tech, full-width **Visit** CTA
- Data: `../shared/data/projects.json`, thumbnails from `https://homepage.theclusterflux.com/thumbnails/`

## Three concept directions

1. **concept-a-void-cathedral** — Dark void default; cyan crystal HUD frames; sharpest geometry; “Void Genome boot screen”
2. **concept-b-funeral-parlor-hud** — Navy tactical HUD; thin scanlines; silver wireframe; resistance dashboard
3. **concept-c-redjuice-dawn** — Dawn silver-white base; magenta accent; softer organic crystal blooms (redjuice key art)
