# Psycho-Pass visual reference (for concept themes)

Source notes for the five MWPSB-inspired previews — not production canon.

## Palette
- **Base:** near-black `#050608`–`#0a0e14`
- **Sibyl cyan:** `#00d4ff`, `#0B69AF` (routine scan, HUD lines, reticles)
- **Alert magenta:** `#ff2d8a`, `#e040fb` (threshold / lethal — use sparingly)
- **Dominator sky-blue:** bullet / paralyzer accent
- **Clinical grey:** `#a4a4a4` labels
- **Makishima contrast:** white `#f7f5f0`, ink black, no neon

## Typography
- Uppercase clinical sans: Rajdhani, Chakra Petch, Share Tech Mono
- Numbers prominent for Crime Coefficient metaphor (decorative, not real scores)

## Motifs
- Hex grids, circular gauges, bracket labels `[ MWPSB ]`
- Cymatic / waveform scans, targeting frames
- Bureau dossiers, stamps, latent-criminal redaction
- Hue cloud: stress spectrum clear → cloudy → criminal

## Data (all concepts)
- `/data/projects.json`, thumbnails from `https://homepage.theclusterflux.com/thumbnails/`
- Search, category filter, featured, **Visit only**
- Shared: `theme-registry.js`, `theme-landing.js`, `theme-switcher.js`
